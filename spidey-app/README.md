# Spidey 3D (React + Three.js)

Double-click **START-SPIDEY.bat** (needs Node.js) → the app opens at http://localhost:4173.

- Dev mode: `npm install` then `npm run dev`
- Build for hosting: `npm run build` → drag `dist` to https://app.netlify.com/drop
- Desktop icon: right-click `Create-Desktop-Icon.ps1` → Run with PowerShell

Full guide (files, AI, RAG, agent, Flutter, settings): see `../DOCUMENTATION.md`.
