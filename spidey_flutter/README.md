# Spidey 3D – Flutter native shell

A Talking-Tom-style 3D Spider-Man assistant.

* The **3D scene + UI** is the React / Three.js web app in `..\spidey-app` (built into `dist`).
* This **Flutter app** is a thin native shell around it:
  * it serves the web build from Flutter assets through a tiny localhost server (`http://localhost:8642`),
  * shows it full-screen in `flutter_inappwebview`,
  * and gives the web app **native speech-to-text, text-to-speech and CORS-free HTTP fetch** through a JavaScript bridge
    (the Android WebView has no Web Speech API).

```
spidey_flutter\
├─ lib\main.dart                    ← the whole Flutter app
├─ pubspec.yaml                     ← packages, asset folders, launcher-icon config
├─ analysis_options.yaml
├─ copy_web.ps1                     ← copies ..\spidey-app\dist  →  assets\web
├─ android_overrides\AndroidManifest.xml   ← copy into android\app\src\main\ after "flutter create"
└─ assets\web\                      ← filled by copy_web.ps1 (empty placeholders for now)
```

Only `lib\`, `pubspec.yaml` and the manifest are provided. The platform folders (`android\`, `ios\`, `windows\`)
are generated by `flutter create` in step 2.

---

## 1. Install the tools (one time, Windows)

1. **Flutter SDK** – follow <https://docs.flutter.dev/get-started/install/windows>.
   Unzip e.g. to `C:\src\flutter` and add `C:\src\flutter\bin` to your user **PATH**.
2. **Android Studio** – <https://developer.android.com/studio>. During setup install the *Android SDK*,
   *Android SDK Command-line Tools* and *Android SDK Platform-Tools* (Android Studio → Settings → Languages & Frameworks → Android SDK → SDK Tools).
3. **Node.js LTS** – <https://nodejs.org> (needed to build the React app).
4. *(Only for the Windows desktop app)* **Visual Studio 2022** (Community is fine) with the
   **"Desktop development with C++"** workload, and the **Microsoft Edge WebView2 Runtime** (already installed on Windows 11).
5. Turn on **Developer Mode** in Windows (Flutter plugins need symlinks): run `start ms-settings:developers` and switch it on.
6. Open a **new** PowerShell window and run:

   ```powershell
   flutter doctor
   flutter doctor --android-licenses     # answer y to everything
   ```

   Fix anything `flutter doctor` marks with ✗ (the iOS / Xcode line can be ignored on Windows).

## 2. Generate the platform folders

Open PowerShell **inside the `spidey_flutter` folder** and run:

```powershell
cd "C:\Users\<you>\OneDrive - Shell\Documents\Srilu POC\spidey_flutter"
flutter create --project-name spidey_flutter --org com.spidey --platforms android,ios,windows .
```

* `flutter create` on an existing folder only **adds missing files** – it does **not** overwrite the existing
  `lib\main.dart` or `pubspec.yaml`.
* It generates its own `android\app\src\main\AndroidManifest.xml`, so **replace it with ours**:

  ```powershell
  Copy-Item .\android_overrides\AndroidManifest.xml .\android\app\src\main\AndroidManifest.xml -Force
  ```

* It also generates `test\widget_test.dart` (a counter-app test that does not apply here). Delete it:

  ```powershell
  Remove-Item .\test\widget_test.dart
  ```

### Set the Android minimum SDK to 24

Open `android\app\build.gradle` (older Flutter) **or** `android\app\build.gradle.kts` (Flutter 3.29+),
find the `defaultConfig { ... }` block and change the `minSdk` line to:

```gradle
minSdk = 24
```

(If the line reads `minSdkVersion flutter.minSdkVersion`, change it to `minSdkVersion 24`.)

### iOS (only if you build on a Mac)

Add to `ios/Runner/Info.plist` inside the top `<dict>`:

```xml
<key>NSMicrophoneUsageDescription</key>
<string>Spidey listens to you so you can talk to him.</string>
<key>NSSpeechRecognitionUsageDescription</key>
<string>Spidey converts your voice to text to understand you.</string>
<key>NSAppTransportSecurity</key>
<dict>
    <key>NSAllowsLocalNetworking</key>
    <true/>
</dict>
```

and enable the permissions for `permission_handler` in `ios/Podfile` (inside the existing `post_install` block, under
`flutter_additional_ios_build_settings(target)`):

```ruby
    target.build_configurations.each do |config|
      config.build_settings['GCC_PREPROCESSOR_DEFINITIONS'] ||= [
        '$(inherited)',
        'PERMISSION_MICROPHONE=1',
        'PERMISSION_SPEECH_RECOGNIZER=1',
      ]
    end
```

Also set the iOS deployment target to at least 12.0 (`platform :ios, '12.0'` at the top of the Podfile).

## 3. Build the web app and copy it in

```powershell
cd ..\spidey-app
npm install
npm run build                      # creates ..\spidey-app\dist
cd ..\spidey_flutter
powershell -ExecutionPolicy Bypass -File .\copy_web.ps1
```

`copy_web.ps1` deletes `assets\web`, copies `..\spidey-app\dist\*` into it, makes sure `assets\web\assets`, `icons`,
`img` and `models` exist, and **warns you if the build contains a sub-folder that is not listed in `pubspec.yaml`**
(Flutter only bundles folders that are listed – add the printed lines under `flutter: assets:`).

Re-run step 3 every time you change the React app.

## 4. Run / build

```powershell
flutter pub get
dart run flutter_launcher_icons          # app icons from assets/web/icons/icon-1024.png
```

### Android phone

1. On the phone: Settings → About phone → tap *Build number* 7× → Developer options → enable **USB debugging**.
2. Plug it in, accept the prompt, check it shows up with `flutter devices`.
3. Run in debug mode (hot reload, logs in the console):

   ```powershell
   flutter run --dart-define=GROQ_KEY=gsk_xxx --dart-define=TAVILY_KEY=tvly_xxx
   ```

4. Build a release APK:

   ```powershell
   flutter build apk --release --dart-define=GROQ_KEY=gsk_xxx --dart-define=TAVILY_KEY=tvly_xxx
   ```

   The APK is at `build\app\outputs\flutter-apk\app-release.apk`. Copy it to the phone (USB / Drive / WhatsApp to
   yourself), open it and allow *Install unknown apps*. Or install directly: `flutter install`.

`TAVILY_KEY` is optional. The keys are compiled into the app and handed to the web app through the `config` bridge
call – don't publish an APK that contains your personal keys.

### Windows desktop

```powershell
flutter build windows --release --dart-define=GROQ_KEY=gsk_xxx
```

Output: `build\windows\x64\runner\Release\spidey_flutter.exe` (keep the **whole `Release` folder** together –
the exe needs the DLLs and `data` folder next to it). Desktop shortcut: right-click `spidey_flutter.exe` →
*Show more options* → *Send to* → *Desktop (create shortcut)*.

On Windows the native speech-to-text is reported as unavailable (`stt: false`); TTS and fetch work.
(`flutter run -d windows --dart-define=GROQ_KEY=...` runs it in debug mode.)

## 5. The JavaScript bridge

The page is loaded as `http://localhost:8642/index.html?native=1`. The web app calls Dart with

```js
const result = await window.flutter_inappwebview.callHandler('speak', { text: 'Hi!', lang: 'en-IN' });
```

(wait for the `flutterInAppWebViewPlatformReady` window event before the first call).

| Handler | Argument (`args[0]`) | Returns |
|---|---|---|
| `capabilities` | – | `{ stt: bool, tts: true, fetch: true, platform: 'android' \| 'ios' \| 'windows' \| ... }` – `stt` is `false` on desktop, otherwise the result of `speech_to_text.initialize()` |
| `config` | – | `{ groqKey, tavilyKey }` from `--dart-define=GROQ_KEY=...` / `TAVILY_KEY=...` (empty strings if not given) |
| `speak` | `{ text, lang?, rate?, pitch? }` – `lang` default `en-IN`; `rate` is the Web-Speech rate (1.0 = normal; mapped to 0.5 on Android/iOS, used as-is on Windows); `pitch` 0.5–2 | `true` **when finished speaking** |
| `stopSpeak` | – | `true` |
| `listenStart` | `{ lang? }` e.g. `'en-IN'`, `'hi-IN'` | `true` (`false` where native STT is not supported). Starts an **always-on mic**: it auto-restarts after every pause/timeout/error until `listenStop` |
| `listenStop` | – | `true` |
| `fetchText` | `{ url, headers? }` | response body as a string (desktop-browser User-Agent, no CORS); `''` on error |

Dart → JS callbacks (define them on `window.SpideyNative`; each call is guarded, so missing ones are ignored):

| Callback | Payload | When |
|---|---|---|
| `onSpeech(obj)` | `{ text: string, final: bool }` | partial and final recognition results |
| `onSpeechState(obj)` | `{ listening: bool }` | mic started / stopped (also during auto-restarts) |
| `onLevel(x)` | number 0..1 | every 90 ms while speaking (mouth animation, random 0.2–1.0), `0` when done; mic level while listening |
| `onWord()` | – | at each spoken word (TTS progress, Android/iOS) |

```js
window.SpideyNative = {
  onSpeech({ text, final }) { /* show / send text */ },
  onSpeechState({ listening }) { /* mic icon */ },
  onLevel(x) { /* mouth open amount */ },
  onWord() { /* small jaw pulse */ },
};
```

## 6. Troubleshooting

| Problem | Fix |
|---|---|
| **Blank / black screen, spinner forever** | The web build was not copied: run step 3 and check `assets\web\index.html` exists. Make sure every folder of the build is listed under `flutter: assets:` in `pubspec.yaml` (copy_web.ps1 prints the missing ones), then `flutter clean` and run again. Use `chrome://inspect` (Android, debug build) to see console errors. |
| Page loads but 3D model / images missing | Same as above – a sub-folder (e.g. `assets/web/models/xyz/`) is not listed in `pubspec.yaml`. |
| **Mic not working** | Allow the microphone: phone Settings → Apps → Spidey 3D → Permissions → Microphone → *Allow*. Make sure the **Google** app / "Speech Services by Google" is installed and updated (it provides the Android speech recognizer). |
| Android beeps every few seconds | That is the system recognizer restarting (always-on mic). Lower the *media/notification* volume or turn off the beep in Google app settings. |
| Spidey hears himself | Have the web app call `listenStop` before `speak` and `listenStart` afterwards. |
| **No Hindi (or other) voice** | Install the language data: Settings → System → Languages & input → Text-to-speech output → Preferred engine **Speech Services by Google** → ⚙ → *Install voice data* → Hindi (India). |
| `minSdkVersion 21 cannot be smaller than 24` / plugin min SDK errors | Set `minSdk = 24` as in step 2. |
| Gradle asks for a specific NDK version | Add the version it prints as `ndkVersion = "x.y.z"` inside `android { }` in `android\app\build.gradle(.kts)`. |
| `Building with plugins requires symlink support` | Enable Windows Developer Mode (step 1.5). |
| Windows build: `nuget` not found | Download `nuget.exe` from <https://www.nuget.org/downloads>, put it in a folder on your PATH and rebuild. |
| Windows build: compiler errors / no Visual Studio | Install the *Desktop development with C++* workload; re-run `flutter doctor`. |
| Port 8642 already in use | Another copy of the app is running – close it. |
| Groq / Tavily not working | You forgot `--dart-define=GROQ_KEY=...` in the `flutter run/build` command (they are read at compile time). |
